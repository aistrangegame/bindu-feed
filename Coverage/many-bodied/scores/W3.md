## 0 · What this wave is, in one breath

The house starts to remember what he has done with it, and shows it only as light, order and warmth. A story received with attention can close a small circuit — *knowing · willing · doing* — and when it does a mote goes to the Light. As circuits close in a room, the deeper faces of the Trinity come forward there; all five were present from the first day at low light. The whole house warms by its **quietest** room, never by its brightest. The Weave becomes **the Cloth**, the house's master image: rooms as weft, days as warp, every story a stitch, every rhyme a crossing thread. The Archive becomes **a Book that writes itself**: month letters, convergence lines filling its margins, a chapter for every body ending in one more story, a Tree, a Litany, a Dark path read backward, pages that play their own grammars, and a last page that is simply his own offerings arranged as a letter — *it was you, it was always you*. After it, Lalita's confession in images, and then the very first line the app ever showed him, unchanged. The dot learns its states: it wanders, it can be caught, it hides one register away, it splits and it draws the next path. A kept line can be carried. The Point's centre narrates the whole house's walk, and the walk survives a relaunch.

**What he should feel.** Nothing announces itself. No "new", no "level", no "unlocked", no number. Weeks on, the river is a shade warmer than it was; a dot he once caught is gold when he opens the Feed; the Book has margins he does not remember writing. *He couldn't say when that happened.*

**Hard laws for this wave** (CONTRACT §7, GAMEPLAN §2):
- **Progress is visible everywhere and countable nowhere** (the wave's own Done line). Storage may count; no screen, label, VoiceOver value or accessibility hint may.
- **Lit, never locked.** Every face, page, story, room, path and leaf exists from day one. Conditions change light, warmth, order and which face speaks first — never existence. "There is one more" is present and readable from the first day, dim.
- **No mechanism words on screen:** never *circuit, knowledge, will, action, face, Bindu/Sakshi/Lalita/Gaia/Higher Self as labels for a face* (voice names that already render as voices stay voices), *teller, body (as a category), tier, progress, level, warmth, quiet(est), ripen, held light, reveal, confession, chapter, litany as a caption of mechanism*. The single sanctioned breach is Lalita's confession, **in images** (§7.11).
- **The sealed stays sealed** (§18): the position-32 Reveal and the Lalita Pass are never touched. *The Book's last page is a different, authored thing.*
- **Sound:** two voices at most (the Breath + one transient), ceiling 0.55, nothing on load, new tones on 110 × a simple ratio or 136.1. **Never on a low day:** the dot does not hide on a rope day, and the Book's last page does not open itself on one.
- **Accessibility:** every gesture has a stillness twin and a VoiceOver action; Reduce Motion keeps order and hold lengths; Dynamic Type; dim marks ≥ 3:1; every story text reachable by VoiceOver even mid-reveal (including inside Book pages).

## 2 · The measures — `Store/HouseMeasure.swift` (new, pure, unit-tested)

```swift
enum HouseFace: String, CaseIterable { case bindu = "Bindu", sakshi = "Sakshi", lalita = "Lalita", gaia = "Gaia", higherSelf = "Higher Self"
    var depth: Int { [.bindu: 0, .sakshi: 1, .lalita: 2, .gaia: 3, .higherSelf: 4][self]! }
    var hex: String { [.bindu: "#E5533C", .sakshi: "#7B82D4", .lalita: "#9B6BD6", .gaia: "#4A9E6B", .higherSelf: "#C9A07A"][self]! } }

struct HouseLight {                         // published on FeedStore as `@Published private(set) var houseLight` (never `house`: W6 owns `store.ledger`, W7 `store.conditions`)
    let rooms: [String: Double]             // canon key → roomLight 0…1 (rooms with ≥ 1 story only)
    let w: Double                           // the house: the quietest room's light
    let quietest: String?                   // canon key of the quietest room (tie → lower Sort Order)
    func face(_ f: HouseFace, in room: String) -> Double
    func foremost(in room: String) -> HouseFace
    static func build(stories:, received:, circuits:, memory:) -> HouseLight
}
```

**Room light** (per canon key `r`, over Story rows whose `room == r`, Live ∪ Staged):
- `N` = stories in r; `R` = distinct stories in r that are received or met; `C` = circuits closed on stories in r; `M` = `RoomMemory` Σw for r, clamped to [0, 4] (A Maya Game and the Unwritten keep no memory on purpose — their `M` is 0).
- `x = R + 2·C + 0.5·M`, `k = 2 + 0.25·N`, **`roomLight = 1 − e^(−x/k)`**. A room with `N = 0` is not in `rooms` (a room with nothing in it is not quiet; it is unwritten).
- Worked: N = 7 → k = 3.75; one received → 0.23; three received + one circuit → 0.74.

**The house** `w = min(rooms.values)` (0 when `rooms` is empty); `quietest = argmin`. *"Being's halo strengthens only as the darkest light rises"* — the brightest room never lifts the house.

**Face light** (per room r, face f; `C_r` as above):
`light(r, f) = 0.15 + 0.85 · (1 − e^(−max(0, C_r + 1 − 1.5·depth(f)) / 1.5))`
- Every face starts at **0.15** in every room (present, low light) except Bindu, which starts at 0.56 — *bodies speak first on the first day*.
- **Foremost face** = the deepest face whose light ≥ 0.5. It moves Bindu → Sakshi → Lalita → Gaia → Higher Self at **0 · 2 · 3 · 5 · 7** circuits in that room. Never shown as a number; it decides only order and warmth (§5).

**Tests** (`HouseMeasureTests.swift`): the worked values above; `w` is the minimum not the mean (a fixture with one bright and one dark room); a room with N = 0 is excluded; foremost moves exactly at C = 0, 2, 3, 5, 7; every face ≥ 0.15 at C = 0 (none absent); the ground colour at w = 1 keeps `inkPrimary` ≥ 11:1 and `inkMuted` ≥ 4.5:1 (§6.1).
