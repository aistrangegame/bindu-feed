## 1 · Purpose and feel

The rhyme gate made rhyme a key: a body's story stayed hidden until his own memo had been met. W0 took the lock away. W1 gives rhyme back as **something seen and played, never used to open anything**.

The feel is cloth. Two stories that rhyme are two threads of one weave: you see the crossing from across the room (the weft in the river, a thread between two stars), you see the finished edge on a page (the selvedge carrying the other's name), one word in each is the same colour (the lit word), and after the last line the other story's first image is already faintly there (the echo line). You can pick two threads up and lay them together (Join), draw one line across the whole sky and hear what is on it (Sweep), turn rings until they sit true (Rings), touch the dot and watch it become every story this one is also (the splitting dot), flick colour and see where two bodies meet (Khelo). And some pairs are performed: read as one piece through a wordless seam, opened as a spread of two doors, or bound as three panels.

Under it all runs the **Verb Mala**: one bead per verb the house has spoken, brightening as he receives that verb again in another body. Touch a bead and every story that does that thing lights, wherever it is.

**Hard laws for this wave (CONTRACT §7, GAMEPLAN §2):**
- **Nothing counted.** No number of rhymes, beads, members, joins. Brightness, never a figure.
- **Nothing locked.** Rhyme never sets a light tier, never orders access, never hides. A story with no rhyme is a whole story.
- **No mechanism words on screen.** Never "rhyme", "suit", "teller", "verb", "family", "pair", "twin", "convergence", "mala", "join", "sweep" as a label, caption, header or VoiceOver label. The *content* of a field may show (a verb word like *holds*, a title, a convergence line) — its *name* never does.
- **Complete at zero and at hundreds.** With no rhymes at all the app shows no empty frame, no placeholder, no "nothing here yet" — the rhyme surfaces are simply absent (rupakarshini law 22: *missing is absent*). With hundreds, nothing crowds: every surface has a stated cap and a rule for what happens past it (never a "+N").
- **Every gesture has a stillness twin and a VoiceOver action.** Reduce Motion keeps order and hold length; only travel becomes opacity.
- **Sound:** two voices at most (the Breath + one transient), ceiling 0.55, sound only after the first touch of the session, new sounds on the 110 / 136.1 roots.

### 2.2 The rhyme index — new file `Domain/RhymeIndex.swift` (F-065)

One value type in `Domain/` (no SwiftUI, no `Color`), **built off-main whenever the snapshot changes** and published once on `ContentModel` (`private(set) var rhyme = RhymeIndex.empty` — never a new stored property on `FeedStore`, E1; FeedStore forwards `store.rhyme`). Pure, no network, no clock. It is the only place that knows what rhymes with what; every view asks it. It returns **the partner's room key** where a view needs a colour — the view resolves the room's `mark` / `ink` from `RoomCanon`; the index carries no accent and no `Color`.

```swift
struct RhymeIndex {
    /// direct rhymes, symmetric: if A lists B (in any of Rhymes / Rhymed By / legacy), B lists A.
    func rhymes(of id: String) -> [Story]          // ordered: A's own listed order first, then inverse-only links, then by sortOrder
    /// everyone sharing A's family (component via links ∪ same non-empty rhymeFamily), excluding A
    func family(of id: String) -> [Story]          // ordered by sortOrder
    func familyKey(of id: String) -> String?       // nil when family(of:) is empty
    func host(of a: String, _ b: String) -> Story?  // the member carrying a Convergence Line; else the one that is his memo; else the one with the lower sortOrder
    func convergenceLine(_ a: String, _ b: String) -> String?   // host's line if non-empty, else the other's if non-empty, else nil
    func isPair(_ a: String, _ b: String) -> Bool  // direct link
    func litWord(_ a: String, _ b: String) -> String?           // §3.3
    func partnerRoom(of id: String) -> String?     // the first rhyme's room key (the weft bead, the lit word, Rings); nil if no rhyme
    func markGeometry(of id: String) -> (angle: Double, rotation: Double)?   // §3.5, from familyKey; nil if no family
    var verbs: [String]                            // distinct verbs, in house order (§6)
    func stories(withVerb v: String) -> [Story]
    func triptychs: [[Story]]                      // §5.3
}
```

**Build rules (all exact):**
1. Every story in `store.stories` takes part (Live ∪ Staged, CONTRACT §2.3; `Type = Story` only). A partner whose Type is `Swatch`, `Second Letter` or `Waiting Role` is never an edge (CONTRACT §2.6); the Swatch reads its host through its own `Rhymes` (W5). A link to an id not in that set (Draft, Archived, deleted, Point rows, proof rows) is **dropped silently** — never an error, never an empty slot. **Never check `Status` here**: a literal Live check would drop all 338 Staged stories' rhymes.
2. Symmetry: for every `A.rhymeIds ∋ B` with B present, add the edge A–B both ways. The legacy field is one-sided (the body points at the memo); the inverse makes the memo know its body.
3. Components: union-find over edges. Then merge components that share a non-empty `rhymeFamily` on any member.
4. `familyKey`: the most frequent non-empty `rhymeFamily` among the component's members (tie → lexicographically first); if none, `"c:" + smallest record id in the component`. Deterministic across launches (no `hashValue` — use `KathaHash.fnv`, which exists in `Reception/Reception.swift`).
5. `verbs`: distinct non-empty `verb` values, ordered by the lowest `sortOrder` of any story carrying it (the house's own sequence — *read us in a row*), tie → alphabetical. **Never ordered by frequency** (that would be a ranking).
