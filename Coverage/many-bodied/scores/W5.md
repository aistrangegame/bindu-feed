## 0 · What this wave is, in one breath

The house already holds more than he will ever ask for. W5 lets some of it **come to him** — one thing per opening, never the same kind twice running, never on a low day, never by notification — and then **keeps every one of them where he can find it again**. Sixteen kinds of arrival, each with its own seat in the house (the waking ember, the Door, the crossing, the head of the river, a story's margin, a story's foot, World VI, the crossing between two stories), one engine deciding which one this opening carries, one ledger remembering what came.

**What Ashrey should feel.** He cannot predict it and he never waits for it. One morning the ember assembles holding a line he kept a year ago. Another, a held sheet with a gold dot waits in the Door's slot: *a message you left for yourself*. Another, nothing at all happens until, at the foot of the story he just read, three lines from the soil under an old factory are simply there. A role he once saw waiting in the Unwritten is gone; in its place, a dotted gap he can touch. A story he sealed months ago comes back aged, gold at the edges: *You did not go looking for it.* Nothing announces any of it, nothing counts it, and whatever came stays in the Book's margin under *what found you*. On a heavy day — known when the Door opens — nothing comes. The house leads with stillness, and with three small lines at the head of the river.

**This wave adds no story text of its own.** Its words are a handful of registered labels (Appendix B); its content is Track 1's data (§1).

### 2.1 Where it lives
Extend W0's **`Domain/ArrivalRules.swift`** (pure; F-165). The type that runs it is **`ArrivalEngine`** — an **`@Observable @MainActor final class` under `AppModel`** (FORM §3.11.1 "ArrivalEngine (W5)"; F-161), forwarded as `store.arrivals` (never a stored property on FeedStore, never an `ObservableObject` held in a `@Published`); W0's `ArrivalRules` becomes its namespace of rules (R1–R9). Kind-specific eligibility and payload picks go in a new **`Domain/ArrivalPicks.swift`** (pure functions over value snapshots of the content and the ledger — testable without views). Porous days in **`Domain/Porous.swift`**. Every "days between two day-keys" in these files goes through one function, `TimeLaw.days(from: String, to: String) -> Int?` (new, `Domain/TimeLaw.swift`, built on `AirtableService.dayFormatter(timeZone: .current)`; *today* is always `HouseClock.now()`, E8); it measures a thing's own age or anniversary, never a wait between arrivals (R4).

```swift
enum ArrivalKind: String, CaseIterable, Codable {
    case leela, swatch, roleLeft, whatFoundYou, aged, deepTime, sameDay, yearAgo,
         goodMorning, seasonLetter, wager, gift, letter, notice, margin, interlude, lalitaPlay
    // `quiet` is no longer a kind. It is what an opening is when nothing arrives (R3, R7).
}
/// W4's asks — kinds of this engine's Door seat (FORM R-09, F-126): when the opening's lot does
/// not take the Door, the engine fills the one slot from these with W4 §2.3's eligibility and
/// weights (incl. `quiet` 30 on the unmet weather; `quiet` only on the quiet weather). R2 (never
/// the same twice running) holds per case. `wager` and `seasonLetter` are not DoorAsks: they
/// stay overrides (letter › goodMorning-first-time › seasonLetter › wager — FORM's order kept).
/// Everything renders in W4's one slot view; there is no page before the weather.
enum DoorAsk: String, CaseIterable, Codable {
    case askYesterday, askNight, askBetween, doorWords, threeDoors, board, quiet
}
enum ArrivalSeat: String, Codable {
    case waking, door, crossing, riverHead,                 // reached every opening, in this order
         storyMargin, storyClose, worldVI, storyCrossing,   // reached by going (in-register)
         letterMoment                                       // a sealed letter's own moment (veil · turning · call)
}
struct Arrival: Equatable, Codable {
    let kind: ArrivalKind
    let seat: ArrivalSeat
    let ref: String?        // the payload: a record id, a story id, a kept-line id, a wager id
    let line: String        // its first line, for the Book (§6)
}
@Observable @MainActor final class ArrivalEngine {            // under AppModel (F-161)
    func beginOpening()                                        // an opening (W0 F-044): cold launch · resume ≥ 3 h · new local day
    func ask(_ seat: ArrivalSeat, _ ctx: SeatContext = .none) -> Arrival?   // nil = nothing here
    func surfaced(_ a: Arrival)                                // the seat calls it once the arrival is on screen
    func declined(_ a: Arrival)                                // the seat could not render it → back to the bag
    var isLowDay: Bool { get }                                 // W4's Round.isLowDay — incl. the low day known at the opening (R3)
    var isQuietOpening: Bool { get }                           // W4's Round.isQuietOpening, read once in beginOpening()
    func found() -> [FoundRow]                                 // §6
}
enum SeatContext { case none, story(Story), crossing(from: String, to: String), moment(FeedStore.LetterMoment) }
```

### 2.4 One opening, start to end
1. **`beginOpening()`** — **an opening is a cold launch, a resume after ≥ 3 h in the background, or a change of local day** (W0 F-044, FORM R-12; F-155 — the score's old "a foreground resume is *not* one" is struck). The Door is presented over the mounted stack; the crossing keeps the old stack one ‹ away in `NavModel.axisReturn`. New `openingId`, `arrivedThisOpening = false`, `lot = nil`; `isQuietOpening` read once from `Round` (W4).
2. **Waking** asks first. Only `yearAgo` lives here. If it is eligible **from local data alone** (the kept record; no network at this moment), in the bag, not `lastKind`, and the opening is **not a quiet weather** and the day not low, Waking carries it (§4.8) and the opening has its arrival. **On a quiet weather Waking carries nothing** (F-156): the year-ago page waits for an opening that is not quiet.
3. **The Door** asks next. If nothing has arrived yet, the engine **draws the opening's lot** (§2.6) from every kind's eligibility at that moment. Overrides first (R6). If the lot's seat is the Door, it renders **in the one slot** this opening. Otherwise the lot is **held** for its seat, and the slot is filled from W4's `DoorAsk` kinds (or rests at `quiet`).
4. **Every later seat** delivers the lot when it is reached and the lot's seat is that seat. **In-register seats** (storyMargin, storyClose, worldVI, storyCrossing) may also **claim late** (R8).
5. **`surfaced(_:)`** is called by the seat **only once the arrival is actually on screen** (or, for VoiceOver users, focused). It writes the ledger (§2.8), sets `lastKind`, removes the kind from the bag, sets `arrivedThisOpening`.
6. A lot whose seat is never reached this opening was **not** an arrival: it is not recorded, not `lastKind`, and it stays in the bag. Nothing was lost; nothing is owed.

### 2.5 The rules (they replace W0's R1–R6 where they differ; `ArrivalRules`)
- **R1 · One per opening.** After `surfaced(_:)` every seat's `ask` returns nil until the next `beginOpening()` — except R6's letter moments.
- **R2 · Never the same kind twice running.** `lastKind` is never drawn and never claimed. (`DeviceKey.arrivalLastKind`, W0.)
- **R3 · It stands down on a low day.** `isLowDay` = W4's `Round.isLowDay` — **including the low day known at the opening** (the rope after 18:00 yesterday, a Call laid down within 12 h, W7's heavy word; FORM R-11). On a quiet weather the slot holds `quiet` and Waking carries nothing. On a low day **every** `ask` returns nil, overrides included; letters wait (still openable early in the Present, W0 14.12); the Good Morning letter waits (still faint in the Present, §4.9). If the rope is reached *after* an arrival surfaced, nothing is withdrawn and nothing further comes. Nothing else in the house closes. (The low-day **lead**, §7, is not an arrival.)
- **R4 · Eligibility is by condition only.** §2.2's column. No condition compares a date difference against a waiting period between arrivals. Conditions that *are* dates belong to the thing itself — a letter's seal, a wager's carrying (`dueDays`, the form's own return, padakarshini A12), a story's age (days since it was sealed), an anniversary — never to the engine.
- **R5 · Unknown is eligible.** A kind whose data has not loaded at draw time (siblings for `gift`, the notice pool, Mandala/Learning traces for `margin`) counts as eligible. Its seat confirms; an unconfirmed lot is `declined(_:)` and returns to the bag. (This is how the lot can be drawn at the Door without blocking it on four lazy fetches.)
- **R6 · Overrides** (taken before the draw, still under R1 and R3):
  1. **The Good Morning letter, the first time** (never yet in the ledger) — on a porous day, at the Door.
  2. **Leela's first ever** — when no seed has ever surfaced, a seed wins its first eligible Door (W0 §5 row 9).
  3. **A due letter at the crossing** (date · absence · new moon) — it takes the opening's slot; a held lot returns to the bag.
  4. **A letter at its own moment** (veil · turning · call) is **exempt from R1 and R2**: it is his own sealed act, at the condition he chose; deferring it would break his seal. R3 still holds. It is recorded like any arrival.
  5. **The Season Letter** on its season turn (W4 §4.1) — at the Door, taken after override 1 (the Good Morning letter's first time) and before 2.
  6. **A due wager** (W4 §4.5) — at the Door, after 5. Neither 5 nor 6 is in the bag (W4 kept them as overrides: each is his own carried act or the season's own turn). Door order: letter › goodMorning (first time) › seasonLetter › wager › Leela's first ever › the draw › else W4's `DoorAsk` kinds (§2.1) — FORM R-09's override order (letter › season letter › wager) is kept, with the Good Morning letter's first time between the first two. Whatever wins **renders in the one slot**.
- **R7 · The bag (variety without counting).** `DeviceKey.arrivalBag` holds the kinds not yet surfaced in the current **cycle**. The draw is weighted sampling **without replacement** from `bag ∩ eligible − {lastKind}`. When that set is empty, **this opening rests** (nothing arrives) and the bag refills with every drawable kind (all but `letter`, `seasonLetter`, `wager` — the overrides). So within a cycle no kind returns until every other eligible kind has had its turn, and the cycle boundary itself is a rest. The bag is storage, never screen (*"storage may count; the screen may not"*).
- **R8 · Late claim, in-register only.** If the lot is held for an in-register seat and has not surfaced, and he reaches a *different* in-register seat first whose kind is eligible (with that seat's context), in the bag and not `lastKind`, that seat takes the opening and the lot returns to the bag. The early seats (waking, door, crossing, riverHead) never claim late. (This is what lets Deep Time, a margin or a swatch find him on an opening whose lot he never walked to.)
- **R9 · Once surfaced, always findable.** Every surfaced arrival is a row in the ledger, listed in the Book (§6) and exported by CARRY YOUR ROAD; every arrival with a home (a margin, a story's foot, the Waiting Room, the Present) also stays there, at rest, on every later visit.

### 2.6 The draw, exactly
```swift
// ArrivalEngine.drawLot(eligible: [ArrivalKind: Arrival]) -> Arrival?
let pool = bag.intersection(eligible.keys).subtracting([lastKind].compactMap { $0 })
guard !pool.isEmpty else { bag = drawableKinds; return nil }        // R7: the rest
var r = Double.random(in: 0..<pool.map(weight).sum, using: &rng)
for k in pool.sorted(by: { $0.rawValue < $1.rawValue }) { r -= weight(k); if r < 0 { return eligible[k] } }
```
- `rng` is `SystemRandomNumberGenerator` in Release; under the harness, `HarnessConfig`'s arrival RNG seed (`-HarnessSeed n`, W0 F-009) injects a seeded SplitMix64 so a walk is repeatable — no `#if DEBUG` in the engine. The sort is only so a seed means the same order on every device.
- `bag` is mutated only by `surfaced(_:)` (remove) and the refill. Draws do not remove.

#### 2.6.1 Overrides and the draw at the Door
`ask(.door)`: if `arrivedThisOpening || isLowDay` → nil. Else R6.1 → R6.2 → `drawLot`. The result is the lot; return it if its seat is `.door`, else hold it and return nil.

#### 2.6.2 The quiet game finds him (`whatFoundYou`)
GAMEPLAN §3.1: the Codex Game is *"a backstage routing axis that weights 'the quiet game finds him'"*. In `ArrivalPicks.quietGame(stories:received:)`:
1. Candidates = body stories (`isBody`) not in `ReceptionMemory.received`; if none, all body stories.
2. Group by `codexGame` (empty → its own group). Each group's weight = `1 / (1 + r)` where `r` = how many stories of that game he has received (stored, never shown).
3. Weighted pick of a group (same `rng`), then `MirrorDay.pick(ids, key: day + "·found·" + openingId)` inside it.
