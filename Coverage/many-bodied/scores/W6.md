## 0 · What this wave is

**Before W6** the house has many rooms and one hallway. The river is a separate stack under the axis. The Point's seven worlds hold sixty-six library stars and no story. The Light's sixty-nine authored scenes all answer the same touch. The Mirror, the Signal, the Call and the Present are each their own small country. "Story Met" is nearly the only thread between registers.

**After W6** the house is one place, walked in one continuous motion. The river *is* the axis at z = 0. A cloth story can be pressed into a wall in the Chamber; a customer's story can be sent out over the horizon of the Return and come back; the Dance has bodies, a chain, a song that peaks where its listening put it. The sky shows the bodies as faint constellations, the old story's current chapter warm where he has lingered, the Signal's lights crowding toward now, the seeds the Codex fed as dated lights. The Light answers each scene's own gesture. The Mirror walks a year of veils. The Signal echoes the Call. The Call carries tellings that wait for his voice. The Present plants today's memo the moment it is spoken and lays it beside the oldest thing it rhymes with. One gesture lifts him above all of it, and four lenses show the house four ways.

**The test this wave is judged by** (GAMEPLAN §9): *no register is an island; each reads and writes the shared game state.* §1 builds that state, and §11 ("Done means") proves every register both writes it and reads it.

**What Ashrey should feel afterwards.** Nothing is announced. Walking down from the sky, the river simply arrives under him; walking up from the river, the gate is there. He presses a wall in the Chamber and a cloth speaks. Months later the Mirror asks a question with only a "?" for a name. He couldn't say when the house became one house.

## 1 · The shared game state — `HouseLedger` (Slice 26.0)

**Why.** "Story Met" is the only real thread between registers today (readers/02 §5). The Point's walk, the carried motes, the struck niches, the return arcs, the filaments, the Light's growth, the Signal's archive, the Call's word: each lives in its own static, its own key, or nowhere. A register cannot be part of one game if it cannot hear what happened in the others.

**What.** New `Store/HouseLedger.swift`. One `@MainActor final class HouseLedger: ObservableObject`, owned by `FeedStore` as **`store.ledger`** (never `store.house`: W3's `HouseLight` is `store.houseLight`, W7's `HouseConditions` is `store.conditions`). If W3 built its walk store (`Store/WalkStore.swift`, `WalkStore.shared.walk: HouseWalk`), **`HouseLedger` wraps it** (W3's keys keep their names; the ledger reads and writes through it), so there is still one walk.

```swift
enum HouseEvent: String, Codable {
    case received, dwelt, kept, joined, carried, mote, filament, fall, worldPlayed,   // the river, the page, the sky
         kathaRead, danced, struck, sentHome, pointStar,                             // the Point
         lightStood, lightDwelt, carved, moteLanded,                                 // the Light
         veilSeen, signalReceived, callWord, tellingOpened, seedOpened,              // Mirror, Signal, Call, Present
         journeyWalked, lanternArrived, houseSeen, lens                              // §10, §6
}
struct HouseMark: Codable { let kind: HouseEvent; let id: String; let register: String; let day: String; let t: Date; var w: Double = 1 }

@MainActor final class HouseLedger: ObservableObject {
    @Published private(set) var revision = 0            // bumps on every note; views observe this, never the array
    func note(_ kind: HouseEvent, _ id: String, in register: String, weight: Double = 1)
    func has(_ kind: HouseEvent, _ id: String) -> Bool
    func weight(_ kind: HouseEvent, _ id: String) -> Double          // Σ w, for dwell-like kinds
    func ids(_ kind: HouseEvent, since day: String? = nil) -> [String] // newest first, deduped
    func last(_ kind: HouseEvent) -> HouseMark?
    func dwellByRoom(days: Int) -> [String: Double]                   // §7.3 current chapter
}
```

- **Storage.** UserDefaults `bindu.house.events`: a JSON array, append-only, newest last. When it passes 4,000 marks, the oldest 1,000 are folded: marks of the same `kind` and `id` merge into one, `w` summed, `t` = the latest. Nothing he did is dropped, only compressed. `bindu.house.firstDay` is written once, on the first launch of a W6 build (fallback for reads: the earliest App Activity date already fetched; else today).
- **Rule of the ledger.** It is local state about his walk, read as **light, order, warmth and which line speaks**. It never gates. No read ever turns it into a number on screen. App Activity writes (Story Met, Veil Lifted, Walk Completed…) are unchanged and still go through `AirtableWriter`; the ledger is the device-side mirror every register can read without a fetch.
- **FORGET ME** clears `bindu.house.events` and sets `bindu.house.firstDay` to today. **CARRY YOUR ROAD** exports it as dated lines in words (`TimeWords`), kinds as words ("a story received", "a wall pressed"), titles not ids, never counts. Add both rows to `STATE.md`.
- **Migration.** On first launch: copy in what already exists — `bindu.kathas.received` → `received`; `bindu.filaments` → `filament`; `bindu.light.carved` → `carved`; `bindu.signal.received` → `signalReceived`; W3's walk state, if separate, by reference (not copied).
