## 3 · The G0 hold engine (native)

**File:** `Components/HoldEngine.swift`. One engine for every hold. It is built from padakarshini G0 (`/mnt/skills/user/padakarshini/references/gestures.md` §G0) and moved to the display link. **Final numbers per FORM §3.6 (F-030).**

```swift
@Observable @MainActor final class HoldEngine {         // @Observable, never ObservableObject (E2)
    struct Spec { var up: Double; var down: Double = 0.62; var name: String; var family: HoldFamily; var view: HoldView; var travel: Bool = false }
    // name = the act ("open it now"); family = its meaning (FORM §3.6); view = .ring (an act on a thing) | .ember (an act that gives his own)
    enum Drive { case hand, key, stillness }
    private(set) var p: Double = 0                      // 0…1
    private(set) var phase: Phase = .rest               // .rest · .holding · .committed · .draining · .done
    var spec: Spec
    var onCommit: () -> Void = {}                       // the visual commit + haptic latch ONLY, at p == 1
    var onComplete: () -> Void = {}                     // THE ACT — navigation, writes, EVERY SoundEngine call, permissions — only on lift after commit
    func press(_ d: Drive = .hand)                      // target = 1; draws the press preview; starts the link if stopped
    func release()                                      // committed → done + onComplete(); else target = 0 (drain)
    func cancel()                                       // view disappeared / second finger: drain silently, never complete; invalidates the link
    func completeForAccessibility()                     // the VoiceOver / named-action door: onCommit() then onComplete(); used by W3–W6
}
```

- **Tick** (`CADisplayLink`, `preferredFrameRateRange = 60…120`, held **through a weak proxy** so the engine is never retained by the run loop; invalidated in `cancel()` and in `deinit`), with `dt = min(1/15, link.targetTimestamp − last)`:
  - `p += target > p ? dt/spec.up : −dt/spec.down`, clamped to [0, 1].
  - At `p ≥ 1` while holding and not yet committed: `phase = .committed`, then `onCommit()`. The link stops (nothing animates while held at full).
  - At `p == 0` with target 0: `phase = .rest`, and the link stops. **No loop runs at rest.** The link also stops when the host is not frontmost (14a.5).
- **Press preview.** Within one frame of touch-down the track is drawn at `p = 0` (ring track 0.22 · ember track 0.14) with a tick haptic (0.4 / 0.3) — *press and see* teaches every hold (FORM §3.8.2). An early lift drains without harm.
- **Never fails.** An early release drains at `down` (0.62 s default; 0.75 for the Turning). No failure sound. No jolt to zero. Pressing again resumes from the current `p`. It never restarts from 0, which is the `HoldEmber` fault.
- **Commit and lift.** At the threshold only the **visual commit and the medium haptic latch** happen. On the lift: navigation, writes, **every `SoundEngine` call** (a hold's answering tone sounds on the lift, never at commit), permissions.
- **Durations by meaning (FORM §3.6).** A new hold takes its family's length; an existing designed hold keeps its own (14.0's table names each one's family):

  | Family | Up / drain | View | W0 members |
  |---|---|---|---|
  | take on lightly | 0.9 / 0.62 | ring | — (W3's Will line, W1's Mala bead) |
  | commit / choose | 1.2 / 0.62 | ring | Gift appreciate · empty summit |
  | going down | 1.25 / 0.62 | ring | peel · Floor door · Floor go-down ×3 · Call go-down 1.3 (existing, kept) |
  | give a word | 1.4 / 0.62 | ember | Codex `give it` · the hall's `add it` |
  | seal | 1.6 / 0.62 | ember | Present seal · seal forward (Rite, Light) · Floor carve |
  | open early | 2.2 / 0.62 | ring | a letter early |
  | lay down | 2.6 / 0.62 | ember | Call lay |
  | existing, kept | as designed | ring / ember | Resonance Depth 1.5 · rewind 2.2 · Compose 2.3 · Signal tratak 2.6 · Turning 2.9 / 0.75 · the Light's carve (scene-authored, up to 4.2) |

- **Cancel.** Movement over **10 pt** cancels a stationary hold (`release()`, so it drains); **24 pt only for travel holds** (`spec.travel = true`: the Stack's drop, the drink opening, G1 read). **A second finger** (touch count ≥ 2) releases any live hold silently and yields to the Call or Pointy.
- **Stillness drive.** The **StillnessConductor** (14a.8) calls `press(.stillness)` when the surface's twin is ready, on the exhale; it drives at the same up rate. Any touch hands back from the current `p` (`release()` drains what stillness gave, then the hand's own `press(.hand)` continues). A hold whose completion writes a touch-budget kind is never completed by stillness on an untouched surface. Thresholds live in GESTURES.md (the Turning 1 breath; `.lit` 4.6 s, G2's accumulator).
- **Keys.** A hardware keyboard's held Return or Space on the focused control calls press/release (`.onKeyPress(phases: [.down, .up])`, iOS 17+). Key repeat is ignored.
- **Reduced Motion.** Duration and order are unchanged. Only the fill is drawn in quarter steps (`(p*4).rounded(.down)/4`), and the end state shows at completion.
- **Haptics** (through `Haptics.hold`, the one engine, 14a.7; the hold latch has priority over room turns and the pulse):
  - press: the preview tick, intensity 0.4, sharpness 0.3;
  - holding: a continuous event whose intensity ramps 0.15 → 0.6 with `p`, sharpness 0.3;
  - commit: a medium impact (the latch);
  - early release: nothing.
- **Accessibility.**
  - The host view: `.accessibilityAddTraits(.isButton)`; label = the act's name — **if the name already begins with `hold`, no prefix; otherwise `hold to ` + the name** (never `hold to hold it in silence`); `.accessibilityAction(named: spec.name) { engine.completeForAccessibility() }`. This runs `onCommit` and then `onComplete`, and is the VoiceOver door, equal to the hold.
  - While holding, `accessibilityValue` is `holding`, then `held`. **Never a percentage.**
- **Views (by meaning).** `HoldRing` (an act on a thing: open, go down, throw, draw, look into) and `HoldEmberView` (an act that gives his own: seal, give, release, carve, add) read the `@Observable` engine and draw `p`. The ring: track at 0.22, arc `trim(0,p)` 1.6 pt round, centre dot `6 + 8p`. The ember: track at 0.14, arc 1.4 pt, dot `10 + 6p`, shadow `10 + 10p`, breathing ×(0.94 + 0.12·`Breath.value(at:)`) — at rest an ember breathes (`emberWake` 3.6 s, ×0.97–1.045) so it looks holdable.
- **Gesture binding.** A `DragGesture(minimumDistance: 0)`: `onChanged` → `press` once (and the cancel distance above); `onEnded` → `release`. `onDisappear` → `cancel()`.
- **Tests** (`Bindu FeedTests/HoldEngineTests.swift`, driving `tick(dt:)` directly):
  - a full hold completes only on release; no `SoundEngine` call happens before the lift (a spy);
  - an early release completes nothing and returns to 0 in `down` seconds;
  - press, release, press resumes from the drained value;
  - 11 pt of movement cancels a stationary hold; 11 pt does not cancel a travel hold;
  - a second touch releases silently;
  - **a view dismissed mid-hold leaves no display link running** (the weak proxy is invalidated);
  - Reduced Motion keeps the duration;
  - the accessibility action completes; the label rule (`hold in silence` stays `hold in silence`; `open it now` becomes `hold to open it now`).
