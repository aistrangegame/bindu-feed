# archive/ — retired, kept for history only

Everything in this folder is **superseded**. It describes earlier eras of the app (Phase 1–7,
and the Phase 9 handoff) and no longer reflects current routes, archetypes, data, or — most
importantly — the current **design**. **Do not build from anything in here.**

**The current sources of truth live elsewhere, in this precedence order** (see
[`Bindu Feed/CLAUDE.md`](../Bindu%20Feed/CLAUDE.md) for the full map):

1. `canon/` — frozen verbatim wording, Hz/number tables, the 66 Point stars.
2. `Claude Design Round 1/The Instrument v3.html` — the blessed, shader-driven unified design
   (feel, geometry, interaction), governed by `Claude Design Round 1/docs/`.
3. `Claude Design Round 1/comps/` — per-register detail, subordinate to the Instrument.

## What's in here

- `BINDU_FEED_CLAUDE_CODE.md` — the May master spec (6-route / 8-archetype world; Make.com
  "not yet wired" — all stale). Retained for wording history.
- `A Strange Feed/` — the June HTML screen comps + screenshots for Phase 1–7.
- `bindu-feed-phase9-handoff/` — the **June 2026 Phase-9 design handoff bundle**. Its
  `BINDU_FEED_PHASE_9_NEW_LAYER.md` still reads like a live build spec but that work shipped on
  2026-06-14 and has since been superseded by the Instrument era. Moved here (Aug 2026) because
  it carried no "superseded" banner and was the main risk of building to the wrong source.
  Note: its `AIRTABLE-DATA-TRUTH.md` schema is still accurate but is mirrored live in
  CLAUDE.md §6; its `soul/` skill (tone/ethic) is still worth reading as intent, not build spec.
- `bindu-feed-phase9-audit.md` — a point-in-time Phase-9 code audit (2026-06-14); its punch
  list was resolved and folded into CLAUDE.md.
- `bindu-feed-snapshot.md` — a verbatim code snapshot from 2026-06-04, pre-Phase-9.

Fully recoverable from git history if ever needed.
